Week 2: Footprinting, Reconnaissance & Network Scanning

Overview

This document presents my Week 2 activities for the Networkwalks Cybersecurity Internship (Batch B084). It focuses on practical learning in footprinting, information gathering, network scanning, port analysis, and network topology mapping using Kali Linux.

Scope & Target Information

- Local Network Scanning: 10.0.0.0/24
- Additional Practice Target: scanme.nmap.org
- Tools Used: Kali Linux, WHOIS, WhatWeb, Nslookup, cURL, Wafw00f, DNSRecon, Nmap, Zenmap

Summary of Activities

1. WHOIS Lookup: Practised retrieving domain registration information.
2. WhatWeb Technology Fingerprinting: Explored website technology identification.
3. Nslookup DNS Resolution: Practised resolving domain names and obtaining DNS information.
4. cURL HTTP Header Inspection: Examined HTTP response headers.
5. Wafw00f Detection: Learned about Web Application Firewall detection.
6. DNSRecon Enumeration: Practised DNS enumeration techniques.
7. Nmap Scanning: Performed network scanning and observed port and service information.
8. Zenmap Intense Scan: Analysed network scan results using the Zenmap graphical interface.
9. Ports / Hosts View: Examined detected hosts, ports, protocols, and services.
10. Network Topology: Visualized the local network topology.
11. Host Details: Explored detailed information about selected hosts.

- Performed a separate practice scan using scanme.nmap.org.

Conclusion

Successfully completed practical learning activities in footprinting concepts and network scanning. Gained hands-on experience with Kali Linux, Nmap, and Zenmap, improving my understanding of host discovery, port analysis, service identification, and network topology mapping.
